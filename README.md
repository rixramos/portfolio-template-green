# GitHub Ready Portfolio

This portfolio is fully static and does not require:

- Vercel
- Vite
- React
- Node.js
- npm install

## Files

- `index.html`
- `style.css`
- `script.js`

## Upload to GitHub

1. Create a new repository on GitHub.
2. Upload all files from this folder.
3. Go to:
   - Settings
   - Pages
4. Under **Branch**, select:
   - `main`
   - `/root`
5. Save.

Your portfolio will automatically be deployed using GitHub Pages.

## Customization

Update the following:

- Email address in `index.html`
- Name and text content
- Skills
- Experience
- Social links
